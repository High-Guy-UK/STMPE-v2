# STMPE-v2

A de-minified (beautified) copy of the **SMPTE v2** stylesheet used by the BroadcasTheNet site theme.

- `style.css` — the full stylesheet, expanded to one declaration per line with consistent 2-space indentation. Content is byte-equivalent to the original (only whitespace/formatting changed; all 331 rule blocks and 79 comments preserved).
- `index.html` — a simple landing page served via GitHub Pages that links to the raw stylesheet.

## GitHub Pages

Once Pages is enabled (branch `main`, root), the files are available at:

- Page: `https://<owner>.github.io/STMPE-v2/`
- Raw CSS: `https://<owner>.github.io/STMPE-v2/style.css`

> Note: the stylesheet references relative asset paths (e.g. `images/bg.gif`) that are not included here, so the CSS is provided for reference/reading rather than as a drop-in working theme.
