# STMPE-v2

A self-contained dark theme stylesheet — near-black greys with subtle gradients, a single azure accent, clean self-hosted typography, and modernised assets.

- `style.css` — the full stylesheet.
- `assets/`, `fonts/`, `images/` — self-hosted fonts and image assets referenced by the stylesheet.
- `index.html` — a small landing page (served via GitHub Pages) that links to the raw stylesheet.

## GitHub Pages

The files are served from GitHub Pages (branch `main`, root):

- Page: `https://<owner>.github.io/STMPE-v2/`
- Raw CSS: `https://<owner>.github.io/STMPE-v2/style.css`
